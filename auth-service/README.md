# Auth Service

This Spring Boot service will handle user identity and access control for NexusAI.

## Responsibilities

- User signup and login
- JWT management
- Refresh token lifecycle
- Role-based access control
- Session and permission enforcement

## Technologies

- Spring Boot
- Spring Security
- PostgreSQL
- Redis
- JWT

## Next Steps

1. Define user and role entities.
2. Implement login/signup REST API.
3. Add JWT filter and RBAC policies.
