# Code Review Service

This service will provide AI-powered code review, security scanning, and test generation.

## Responsibilities

- Analyze pull requests and diffs
- Perform security and quality checks
- Generate AI review comments
- Create test generation suggestions

## Technologies

- Spring Boot
- OpenAI / LLM APIs
- SonarQube connectors
- Redis caching
- Kafka event publishing

## Next Steps

1. Define code review workflow.
2. Add code diff ingestion endpoints.
3. Connect to AI service for review analysis.
